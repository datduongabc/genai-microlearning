# NFR02 and image scan, 2026-11-18

## Acknowledgement times (NFR02)

NFR02 asks that an upload or generation request be answered within 2 s (p95), without the file transfer.

Method: the load stack of `devops/loadtest` (two API containers, one worker, the mock model, real Postgres, Redis and embedder).
`drive_generation.py seed --users 40`, then `drive_generation.py ack --concurrency N --out ack.json`, reseeded before each run.
Each of the 40 lecturers asks to upload a PDF, sends it (not timed), completes the upload, then asks for a module, a flashcard set and a video.
Raw rows: `2026-11-18-nfr/ack.json`.

| Request | p50, 10 at once | p95, 10 at once | p50, 40 at once | p95, 40 at once |
| --- | ---: | ---: | ---: | ---: |
| Ask to upload | 0.06 s | 0.16 s | 0.20 s | 0.25 s |
| Complete the upload | 0.05 s | 0.07 s | 0.18 s | 0.22 s |
| Generate a module | 0.05 s | 0.08 s | 0.20 s | 0.23 s |
| Generate flashcards | 0.06 s | 0.09 s | 0.22 s | 0.26 s |
| Generate a video | 0.05 s | 0.09 s | 0.20 s | 0.23 s |

All 400 requests succeeded.
The slowest p95 is an eighth of the limit.
One run each, on one laptop that also ran the load generator.

A rerun of the API read test at one API container served 220 requests per second (p95 2.9 s, no failures), against 199 on 2026-11-05.

Raw findings: `2026-11-18-nfr/image-scan-*.json`.

| Image | Critical (fixable) | High (fixable) | In Python packages |

| backend | 12 (11) | 454 (72) | 11 critical, 72 high |
| gateway | 0 | 53 (6) | 6 high |

The fixable critical findings are in Pillow 12.3.0 (fixed in 13.0.0) and certifi.
None of the operating-system findings has a fixed Debian version yet.
ECR's basic scan on push looks only at operating-system packages, so it never reported the Python ones.

## Accessibility (NFR06)

axe-core 4.10.2 ran the WCAG 2.2 A and AA rules on six pages of the dev server with a mocked API: sign-in, registration, the course list, a course, the flashcard editor and the learner page.
No rule was violated.
axe could not decide the contrast of the text areas, so it was computed: text 17.08:1 on white, and the muted text used for placeholders and hints at least 4.66:1 (on `--bg-subtle`), against 4.5:1 for AA.
By keyboard alone: the sign-in form in order (email, the forgotten-password link, password, submit); a module generated through the "Tạo nội dung" menu and its dialog, which took the focus and gave it back to the menu button on Escape; an edited card saved by tabbing to "Lưu thay đổi" and pressing Enter.
Focus was visible on every element reached.
Not checked: the module editor, the video editor, the admin and study pages.
